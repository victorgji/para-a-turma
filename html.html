1. Estrutura Básica e Metadados

  • <!DOCTYPE html>: Declaração obrigatória que avisa o navegador que a página utiliza a versão mais recente do HTML (HTML5).
  • <html>: A tag raiz que envolve todo o conteúdo da página. O atributo lang="pt-br" define o idioma principal.
  • <head>: Contêiner que guarda os metadados (informações sobre o documento) que não aparecem diretamente para o usuário.
  • <title>: Define o título da página que aparece na aba do navegador e nos resultados de busca.
  • <meta>: Define metadados como codificação de caracteres (charset="UTF-8"), configurações de viewport para responsividade, autor e descrição.
  • <link>: Usada para conectar o documento a recursos externos, mais frequentemente folhas de estilo CSS (.css) ou favicons.
  • <style>: Permite inserir regras de estilo CSS diretamente dentro do documento HTML.
  • <script>: Usada para incorporar ou referenciar códigos JavaScript externos ou internos.
  • <noscript>: Define um conteúdo alternativo para ser exibido caso o navegador do usuário esteja com o JavaScript desativado.
  • <body>: Contém todo o conteúdo visível da página (textos, imagens, links, vídeos, etc.).

2. Estrutura Semântica de Layout

  • <header>: Define o cabeçalho de uma página ou de uma seção específica. Geralmente contém logos e menus de navegação.
  • <nav>: Bloco que agrupa links de navegação principal do site.
  • <main>: Define o conteúdo principal e exclusivo da página. Só deve existir um por página.
  • <article>: Representa um conteúdo autônomo e independente que faz sentido por si só (ex: um post de blog, uma notícia).
  • <section>: Define uma seção genérica de conteúdo temático dentro de uma página.
  • <aside>: Define um conteúdo tangencial ou secundário (como barras laterais, anúncios ou caixas de curiosidades).
  • <footer>: Define o rodapé de uma página ou de uma seção (geralmente contém direitos autorais e contatos).
  • <address>: Fornece informações de contato para a pessoa ou organização dona do site ou do artigo.

3. Conteúdo Textual e Organização

  • <div>: Um contêiner genérico em bloco (block-level) usado para agrupar elementos para fins de estilização (CSS) ou script. Não tem significado semântico.
  • <span>: Um contêiner genérico em linha (inline) usado para aplicar estilos ou scripts a partes específicas de um texto.
  • <p>: Define um parágrafo de texto.
  • <h1> a <h6>: Títulos e subtítulos da página, onde h1 é o mais importante e h6 o de menor importância.
  • <hr>: Cria uma quebra temática ou uma linha horizontal divisória.
  • <br>: Produz uma quebra de linha simples no texto.
  • <pre>: Exibe o texto exatamente como foi digitado no código, preservando espaços em branco e quebras de linha.
  • <blockquote>: Usada para indicar uma citação longa de outra fonte, geralmente recuada.

4. Listas

  • <ul>: Define uma lista não ordenada (geralmente com marcadores de bolinha).
  • <ol>: Define uma lista ordenada (numerada ou sequencial).
  • <li>: Define um item de uma lista (usado dentro de ul ou ol).
  • <dl>: Define uma lista de descrição (termos e suas respectivas descrições).
  • <dt>: Define o termo a ser descrito dentro de uma lista de descrição (dl).
  • <dd>: Define a descrição ou definição do termo anterior (dt).

5. Semântica de Texto (Formatação Interna)

  • <a>: Cria um hiperlink para outras páginas, arquivos ou seções da mesma página utilizando o atributo href.
  • <strong>: Indica que o texto tem forte importância ou urgência. Por padrão, o navegador o exibe em negrito.
  • <em>: Enfatiza uma palavra ou trecho, mudando o sentido da frase. Por padrão, o navegador o exibe em itálico.
  • <small>: Representa comentários laterais ou "letras miúdas" (como avisos legais ou direitos autorais).
  • <s>: Indica que o texto não é mais correto, relevante ou preciso (renderiza um risco no meio do texto).
  • <cite>: Define o título de uma obra de arte, livro, música ou filme que está sendo citado.
  • <q>: Usada para citações textuais curtas em linha (o navegador adiciona as aspas automaticamente).
  • <dfn>: Indica o termo que está sendo definido dentro do contexto do texto.
  • <abbr>: Define uma abreviação ou sigla (o atributo title mostra a definição ao passar o mouse).
  • <data>: Associa um conteúdo legível por humanos a um valor legível por máquinas.
  • <time>: Representa uma data ou hora específica no calendário.
  • <code>: Usada para exibir fragmentos de código de computador.
  • <var>: Define uma variável em uma expressão matemática ou de programação.
  • <samp>: Representa a saída (output) de um programa de computador ou sistema.
  • <kbd>: Indica uma entrada do usuário, geralmente teclas do teclado.
  • <sub>: Formata o texto como subscrito (abaixo da linha).
  • <sup>: Formata o texto como sobrescrito (acima da linha).
  • <i>: Usada para termos técnicos, pensamentos ou palavras em outros idiomas (renderiza em itálico).
  • <b>: Usada para chamar atenção para o texto sem dar importância extra (renderiza em negrito).
  • <u>: Renderiza o texto com uma linha sublinhada.
  • <mark>: Destaca ou realça um texto (efeito de caneta marca-texto).
  • <ruby>: Usada para exibir anotações tipográficas ao lado ou acima de caracteres orientais.
  • <rt>: Define a pronúncia ou explicação dos caracteres dentro da tag ruby.
  • <rp>: Define o que exibir caso o navegador não tenha suporte à tag ruby.
  • <bdi>: Isola um trecho de texto que pode estar formatado em uma direção diferente.
  • <bdo>: Força a direção do texto de forma explícita.
  • <ins>: Representa um texto que foi inserido/adicionado ao documento.
  • <del>: Representa um texto que foi deletado/removido do documento.

6. Elementos Multimídia

  • <img>: Incorpora uma imagem na página através do atributo src.
  • <iframe>: Incorpora uma outra página HTML dentro da página atual.
  • <embed>: Contêiner para integração de aplicações externas ou conteúdos interativos de terceiros.
  • <object>: Um contêiner genérico para recursos externos (como plugins, PDFs ou imagens).
  • <param>: Define parâmetros para a tag object.
  • <video>: Incorpora um reprodutor de vídeo nativo na página.
  • <audio>: Incorpora um reprodutor de áudio nativo na página.
  • <source>: Especifica múltiplos recursos de mídia para as tags video, audio ou picture.
  • <track>: Define faixas de texto cronometradas (como legendas) para vídeos ou áudios.
  • <picture>: Permite oferecer diferentes versões de uma imagem dependendo do tamanho da tela.
  • <canvas>: Cria uma área gráfica onde desenhos e animações podem ser renderizados via JavaScript.
  • <svg>: Usado para desenhar gráficos vetoriais diretamente no HTML.
  • <map>: Define um mapa de imagem interativo (com áreas clicáveis).
  • <area>: Define as regiões geométricas clicáveis dentro de um mapa.

7. Tabelas

  • <table>: Declara e envolve uma tabela de dados.
  • <caption>: Define o título ou legenda da tabela.
  • <thead>: Agrupa o conteúdo do cabeçalho da tabela.
  • <tbody>: Agrupa o corpo principal com os dados da tabela.
  • <tfoot>: Agrupa o conteúdo do rodapé da tabela.
  • <tr>: Define uma linha (row) dentro da tabela.
  • <th>: Define uma célula de cabeçalho (título da coluna ou linha).
  • <td>: Define uma célula de dados padrão dentro de uma linha.
  • <colgroup>: Agrupa uma ou mais colunas de uma tabela para fins de estilização.
  • <col>: Define propriedades de coluna para cada coluna dentro de um colgroup.

8. Formulários e Interatividade

  • <form>: Define um formulário para coleta de dados enviados pelo usuário.
  • <label>: Cria uma etiqueta de texto para um elemento de formulário.
  • <input>: Cria campos de entrada de dados variados (texto, senhas, e-mails, botões, etc.).
  • <button>: Cria um botão clicável.
  • <select>: Cria uma lista suspensa (menu dropdown) de opções.
  • <optgroup>: Cria um grupo de opções categorizadas dentro de um select.
  • <option>: Define uma opção individual dentro de um select.
  • <textarea>: Cria uma caixa de texto multilinha.
  • <fieldset>: Agrupa elementos relacionados dentro de um formulário.
  • <legend>: Define um título para o grupo criado pelo fieldset.
  • <datalist>: Define uma lista de opções predefinidas que aparecem como sugestões para um campo input.
  • <output>: Mostra o resultado de um cálculo matemático ou script feito pelo usuário.
  • <progress>: Exibe uma barra de progresso.
  • <meter>: Exibe uma medida escalar dentro de um intervalo conhecido.

9. Elementos Interativos Dinâmicos

  • <details>: Cria um elemento retrátil (menu sanfona) que o usuário pode abrir ou fechar.
  • <summary>: Define o título visível que o usuário clica para abrir/fechar a tag details.
  • <dialog>: Representa uma caixa de diálogo ou janela modal nativa do navegador.
  • <template>: Guarda fragmentos de código HTML que não são renderizados ao carregar a página, mas podem ser usados via JavaScript.
  • <slot>: Usado em Web Components (Shadow DOM) como um localizador para inserir conteúdos customizados.
