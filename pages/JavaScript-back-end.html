JavaScript Back-End & Base: Guia Completo

Sintaxe Básica e Execução (Node.js)

Estrutura de Código JS

// Exemplo de script de servidor/execução no Node.js
const http = require('http');

const server = http.createServer((req, res) => {
    res.writeHead(200, { 'Content-Type': 'text/plain; charset=utf-8' });
    res.end('Servidor JavaScript Back-End Rodando!');
});

server.listen(3000, () => {
    console.log('Servidor ativo em http://localhost:3000');
});

1. Declaração de Variáveis e Tipos de Dados

  • const: Declara uma constante de escopo de bloco. O valor não pode ser reatribuído.
    ▶ Ver Exemplo 
    const PORTA = 3000;
// PORTA = 8080; // Gera TypeError
  • let: Declara uma variável reatribuível com escopo de bloco local.
    ▶ Ver Exemplo 
    let contador = 0;
contador += 1;
  • var: Declara uma variável com escopo de função ou global (legado/evitar em código moderno).
    ▶ Ver Exemplo 
    var nome = 'Servidor';
  • typeof: Operador unário que retorna uma string indicando o tipo do dado.
    ▶ Ver Exemplo 
    console.log(typeof 'Texto'); // "string"
console.log(typeof 123);     // "number"
console.log(typeof true);    // "boolean"
  • instanceof: Testa se a propriedade `prototype` de um construtor aparece em qualquer lugar na cadeia de protótipos de um objeto.
    ▶ Ver Exemplo 
    const data = new Date();
console.log(data instanceof Date); // true
  • Tipos Primitivos: `string`, `number`, `bigint`, `boolean`, `undefined`, `symbol`, `null`.
    ▶ Ver Exemplo 
    const texto = "Backend";
const numero = 42;
const bigIntNum = 9007199254740991n;
const ativo = true;
let indefinido;
const idUnico = Symbol('id');
const nulo = null;

2. Operadores e Estruturas de Controle

  • if / else if / else: Condicional base para desvio de fluxo no código.
    ▶ Ver Exemplo 
    const status = 200;
if (status === 200) {
    console.log('OK');
} else if (status === 404) {
    console.log('Não Encontrado');
} else {
    console.log('Erro de Servidor');
}
  • switch / case / break / default: Avalia uma expressão, combinando o valor com cláusulas `case`.
    ▶ Ver Exemplo 
    const metodo = 'POST';
switch (metodo) {
    case 'GET':
        console.log('Busca dados');
        break;
    case 'POST':
        console.log('Cria dados');
        break;
    default:
        console.log('Método não suportado');
}
  • Operadores de Comparação e Lógicos: `===` (estrito igual), `!==` (estrito diferente), `&&` (AND), `||` (OR), `??` (Nullish Coalescing).
    ▶ Ver Exemplo 
    const usuario = null;
const nomeExibicao = usuario ?? 'Visitante'; // Usa valor padrão se for null/undefined
if (status === 200 && ativo) {
    // faz algo
}
  • Operador Ternário (`? :`): Forma curta para expressão condicional.
    ▶ Ver Exemplo 
    const acesso = idade >= 18 ? 'Permitido' : 'Negado';
  • Encadeamento Opcional (`?.`): Lê o valor de uma propriedade sem causar erro caso a referência seja `null` ou `undefined`.
    ▶ Ver Exemplo 
    const rua = usuario?.endereco?.rua;
  • for / while / do...while: Laços de repetição tradicionais.
    ▶ Ver Exemplo 
    for (let i = 0; i < 5; i++) {
    console.log(i);
}
  • for...in: Intera sobre as propriedades enumeráveis de um objeto.
    ▶ Ver Exemplo 
    const config = { host: 'localhost', port: 3000 };
for (let chave in config) {
    console.log(`${chave}: ${config[chave]}`);
}
  • for...of: Intera sobre objetos iteráveis (Arrays, Maps, Sets, Strings).
    ▶ Ver Exemplo 
    const rotas = ['/users', '/products', '/auth'];
for (let rota of rotas) {
    console.log(rota);
}

3. Funções, Escopo e ES6+

  • function: Declaração tradicional de função.
    ▶ Ver Exemplo 
    function somar(a, b = 0) {
    return a + b;
}
  • Arrow Function (`() => {}`): Sintaxe curta de função que compartilha o mesmo `this` do escopo delimitador.
    ▶ Ver Exemplo 
    const multiplicar = (a, b) => a * b;
  • Rest Parameter (`...args`) / Spread (`...`): Permite representar um número indefinido de argumentos como um array ou espalhar elementos.
    ▶ Ver Exemplo 
    function listar(...itens) {
    return itens;
}
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4]; // [1, 2, 3, 4]
  • Desestruturação (Destructuring): Extrai dados de arrays ou objetos em variáveis distintas.
    ▶ Ver Exemplo 
    const req = { body: { nome: 'Ana' }, params: { id: 10 } };
const { nome } = req.body;
const { id } = req.params;

4. Métodos de Array

  • .push() / .pop(): Adiciona ao final / Remove o último elemento.
    ▶ Ver Exemplo 
    const nums = [1, 2];
nums.push(3); // [1, 2, 3]
nums.pop();   // [1, 2]
  • .shift() / .unshift(): Remove o primeiro / Adiciona no início.
    ▶ Ver Exemplo 
    const lista = ['b', 'c'];
lista.unshift('a'); // ['a', 'b', 'c']
lista.shift();     // ['b', 'c']
  • .map(): Cria um novo array com os resultados da chamada de uma função para cada elemento.
    ▶ Ver Exemplo 
    const idades = [10, 20, 30];
const dobradas = idades.map(n => n * 2); // [20, 40, 60]
  • .filter(): Cria um novo array com todos os elementos que passaram no teste da função.
    ▶ Ver Exemplo 
    const usuarios = [{ idade: 15 }, { idade: 22 }];
const adultos = usuarios.filter(u => u.idade >= 18);
  • .reduce() / .reduceRight(): Executa uma função redutora sobre cada elemento, resultando num único valor.
    ▶ Ver Exemplo 
    const precos = [10, 20, 30];
const total = precos.reduce((acc, curr) => acc + curr, 0); // 60
  • .forEach(): Executa uma dada função em cada elemento do array.
    ▶ Ver Exemplo 
    ['a', 'b'].forEach(item => console.log(item));
  • .find() / .findIndex(): Retorna o primeiro elemento (ou seu índice) que satisfaz a função de teste.
    ▶ Ver Exemplo 
    const lista = [{ id: 1 }, { id: 2 }];
const item = lista.find(o => o.id === 2); // { id: 2 }
const idx = lista.findIndex(o => o.id === 2); // 1
  • .includes() / .indexOf() / .lastIndexOf(): Verifica presença ou posição de elementos.
    ▶ Ver Exemplo 
    const arr = ['a', 'b', 'c'];
console.log(arr.includes('b')); // true
console.log(arr.indexOf('c'));   // 2
  • .slice() / .splice(): Corta o array (sem alterar original) / Altera o conteúdo de um array removendo/substituindo elementos.
    ▶ Ver Exemplo 
    const letras = ['a', 'b', 'c', 'd'];
const sub = letras.slice(1, 3); // ['b', 'c']
letras.splice(1, 1, 'x');       // altera letras para ['a', 'x', 'c', 'd']
  • .some() / .every(): Testa se ao menos um / todos os elementos passam no teste.
    ▶ Ver Exemplo 
    const nums = [1, 2, 3];
const temPar = nums.some(n => n % 2 === 0);  // true
const todosPares = nums.every(n => n % 2 === 0); // false
  • .flat() / .flatMap(): Achata arrays aninhados.
    ▶ Ver Exemplo 
    const matriz = [1, [2, [3]]];
console.log(matriz.flat(2)); // [1, 2, 3]
  • .sort() / .reverse(): Ordena / Inverte a ordem dos elementos de um array no local (in-place).
    ▶ Ver Exemplo 
    const ordem = [3, 1, 2].sort((a, b) => a - b); // [1, 2, 3]
ordem.reverse(); // [3, 2, 1]
  • .join() / .concat(): Junta elementos em string / Concatena dois ou mais arrays.
    ▶ Ver Exemplo 
    const csv = ['usr', 'admin', 'root'].join(';'); // "usr;admin;root"
  • .at() / .fill(): Acessa por índice (aceita negativos) / Preenche elementos com valor estático.
    ▶ Ver Exemplo 
    const arr = [10, 20, 30];
console.log(arr.at(-1)); // 30
console.log(new Array(3).fill(0)); // [0, 0, 0]
  • Array.isArray() / Array.from(): Métodos estáticos de validação e criação.
    ▶ Ver Exemplo 
    console.log(Array.isArray([1, 2])); // true
const letras = Array.from('JS'); // ['J', 'S']

5. Métodos de String

  • .length: Propriedade que indica o comprimento da string.
    ▶ Ver Exemplo 
    console.log("NodeJS".length); // 6
  • .trim() / .trimStart() / .trimEnd(): Remove espaços em branco das extremidades.
    ▶ Ver Exemplo 
    const texto = "  código  ".trim(); // "código"
  • .toLowerCase() / .toUpperCase(): Converte para minúsculas ou maiúsculas.
    ▶ Ver Exemplo 
    console.log('API'.toLowerCase()); // "api"
  • .includes() / .startsWith() / .endsWith(): Verificações de busca dentro da string.
    ▶ Ver Exemplo 
    const url = '/api/v1/users';
console.log(url.startsWith('/api')); // true
console.log(url.includes('v1'));      // true
  • .split(): Divide uma String em um array de substrings.
    ▶ Ver Exemplo 
    const partes = '127.0.0.1'.split('.'); // ['127', '0', '0', '1']
  • .replace() / .replaceAll(): Substitui padrões usando string ou Expressões Regulares (RegEx).
    ▶ Ver Exemplo 
    const rota = '/user/:id'.replace(':id', '123'); // "/user/123"
  • .substring() / .slice(): Extrai trechos da string.
    ▶ Ver Exemplo 
    const hash = 'sha256-abcdef'.slice(7); // "abcdef"
  • .padStart() / .padEnd(): Preenche a string com outra até atingir determinado comprimento.
    ▶ Ver Exemplo 
    const cod = '5'.padStart(4, '0'); // "0005"
  • .charAt() / .charCodeAt(): Retorna o caractere ou código UTF-16 na posição.
    ▶ Ver Exemplo 
    console.log('Backend'.charAt(0)); // "B"
  • .repeat(): Retorna uma nova string contendo o número especificado de cópias da original.
    ▶ Ver Exemplo 
    console.log('='.repeat(5)); // "====="

6. Métodos de Objetos, Classes e Protótipos

  • Object.keys() / Object.values() / Object.entries(): Extrai chaves, valores ou pares [chave, valor].
    ▶ Ver Exemplo 
    const user = { name: 'Dev', role: 'Admin' };
console.log(Object.keys(user));   // ['name', 'role']
console.log(Object.values(user)); // ['Dev', 'Admin']
console.log(Object.entries(user));// [['name', 'Dev'], ['role', 'Admin']]
  • Object.assign() / Object.fromEntries(): Copia valores entre objetos ou converte pares chave-valor em objeto.
    ▶ Ver Exemplo 
    const destino = {};
Object.assign(destino, { a: 1 }, { b: 2 }); // { a: 1, b: 2 }
  • Object.freeze() / Object.seal(): Congela (impede qualquer alteração) ou sela (impede adições/remoções de propriedades).
    ▶ Ver Exemplo 
    const config = Object.freeze({ db: 'postgres' });
// config.db = 'mysql'; // Silenciosamente falha ou gera erro no modo estrito
  • class / constructor / extends / super: Programação Orientada a Objetos (POO).
    ▶ Ver Exemplo 
    class Controller {
    constructor(nome) {
        this.nome = nome;
    }
}

class UserController extends Controller {
    constructor(nome, tabela) {
        super(nome);
        this.tabela = tabela;
    }
}
  • static / get / set: Métodos estáticos da classe e acessadores de propriedades.
    ▶ Ver Exemplo 
    class Auth {
    static autenticar() {
        return true;
    }
    get token() {
        return 'xyz123';
    }
}
console.log(Auth.autenticar()); // true

7. Programação Assíncrona (Promises, Async/Await)

  • Promise: Objeto representando a eventual conclusão ou falha de uma operação assíncrona.
    ▶ Ver Exemplo 
    const minhaPromise = new Promise((resolve, reject) => {
    let sucesso = true;
    if (sucesso) resolve('OK');
    else reject('Erro');
});
  • .then() / .catch() / .finally(): Métodos de encadeamento de Promises.
    ▶ Ver Exemplo 
    minhaPromise
    .then(resultado => console.log(resultado))
    .catch(erro => console.error(erro))
    .finally(() => console.log('Finalizado'));
  • async / await: Açúcar sintático sobre Promises para escrever código assíncrono sequencial.
    ▶ Ver Exemplo 
    async function buscarDados() {
    try {
        const resposta = await fetch('https://api.exemplo.com');
        const dados = await resposta.json();
        return dados;
    } catch (err) {
        console.error('Falha:', err);
    }
}
  • Promise.all() / Promise.allSettled(): Executa múltiplas Promises em paralelo.
    ▶ Ver Exemplo 
    const p1 = Promise.resolve(10);
const p2 = Promise.resolve(20);
Promise.all([p1, p2]).then(res => console.log(res)); // [10, 20]
  • Promise.race() / Promise.any(): Retorna a primeira Promise que resolver/rejeitar ou a primeira que resolver com sucesso.
    ▶ Ver Exemplo 
    Promise.race([p1, p2]).then(primeiro => console.log(primeiro));

console.log(path.extname(caminhoAbsoluto)); // ".png"

11. Criptografia e Segurança (Módulo Nativo `crypto` e Utilitários)

  • crypto.createHash(): Cria um objeto Hash para gerar resumos criptográficos unidirecionais (SHA-256, MD5, etc.).
    ▶ Ver Exemplo 
    const crypto = require('crypto');
const hash = crypto.createHash('sha256').update('minhaSenha123').digest('hex');
console.log(hash);
  • crypto.createHmac(): Cria um HMAC (Código de Autenticação de Mensagem Baseado em Hash) usando uma chave secreta.
    ▶ Ver Exemplo 
    const crypto = require('crypto');
const hmac = crypto.createHmac('sha256', 'chaveSecretaServidor')
                   .update('dadosDaMensagem')
                   .digest('hex');
console.log(hmac);
  • crypto.randomBytes(): Gera bytes aleatórios criptograficamente seguros (ideal para criação de salts, IVs e tokens de acesso).
    ▶ Ver Exemplo 
    const crypto = require('crypto');
const token = crypto.randomBytes(32).toString('hex');
console.log(token);
  • crypto.createCipheriv() / crypto.createDecipheriv(): Criptografia e descriptografia simétrica reutilizável com chave e IV (ex: AES-256-GCM / CBC).
    ▶ Ver Exemplo 
    const crypto = require('crypto');
const chave = crypto.randomBytes(32);
const iv = crypto.randomBytes(16);

// Criptografar
const cipher = crypto.createCipheriv('aes-256-cbc', chave, iv);
let encriptado = cipher.update('Dado Secreto', 'utf8', 'hex');
encriptado += cipher.final('hex');

// Descriptografar
const decipher = crypto.createDecipheriv('aes-256-cbc', chave, iv);
let decriptado = decipher.update(encriptado, 'hex', 'utf8');
decriptado += decipher.final('utf8');
  • crypto.scrypt() / crypto.pbkdf2(): Funções de derivação de chave (KDF) resistentes a ataques de força bruta, ideais para senhas.
    ▶ Ver Exemplo 
    const crypto = require('crypto');
const salt = crypto.randomBytes(16);

crypto.scrypt('senhaDoUsuario', salt, 64, (err, derivedKey) => {
    if (err) throw err;
    console.log(derivedKey.toString('hex'));
});
  • crypto.generateKeyPairSync(): Gera pares de chaves assimétricas (Chave Pública e Privada - ex: RSA, ECC).
    ▶ Ver Exemplo 
    const crypto = require('crypto');
const { publicKey, privateKey } = crypto.generateKeyPairSync('rsa', {
    modulusLength: 2048,
});
  • crypto.timingSafeEqual(): Compara dois buffers em tempo constante para evitar ataques de análise de tempo (Timing Attacks).
    ▶ Ver Exemplo 
    const crypto = require('crypto');
const bufA = Buffer.from('tokenInformado');
const bufB = Buffer.from('tokenEsperado');
const saoIguais = crypto.timingSafeEqual(bufA, bufB);
  • crypto.subtle (Web Crypto API): API nativa padrão W3C para operações criptográficas assíncronas.
    ▶ Ver Exemplo 
    const encoder = new TextEncoder();
const data = encoder.encode('Texto Confidencial');
const hashBuffer = await crypto.subtle.digest('SHA-256', data);
  • bcrypt.hash() / bcrypt.compare(): Algoritmo padrão de mercado para hashing e checagem segura de senhas (Pacote externo `bcrypt`).
    ▶ Ver Exemplo 
    const bcrypt = require('bcrypt');
const hash = await bcrypt.hash('minhaSenha123', 10);
const ehValido = await bcrypt.compare('minhaSenha123', hash); // true
  • jwt.sign() / jwt.verify(): Assinatura e validação de tokens de autenticação JSON Web Token (Pacote externo `jsonwebtoken`).
    ▶ Ver Exemplo 
    const jwt = require('jsonwebtoken');
const token = jwt.sign({ id: 1 }, 'minhaChaveSecreta', { expiresIn: '1h' });
const payload = jwt.verify(token, 'minhaChaveSecreta');
