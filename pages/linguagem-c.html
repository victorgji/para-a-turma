Linguagem C: Guia Completo para Back-End

Estrutura Básica de um Servidor/Programa em C

estrutura basica

#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[]) {
    /* Ponto de entrada do programa */
    printf("Servidor C inicializado.\n");
    return 0;
}

1. Estrutura Básica e Compilação

  • #include: Diretiva de pré-processador para incluir bibliotecas padrão do sistema ou arquivos de cabeçalho locais (.h).
    ▶ Ver Exemplo 
    #include <stdio.h>
#include "meu_header.h"
  • main(): Função principal onde a execução do programa em C é iniciada pelo sistema operacional.
    ▶ Ver Exemplo 
    int main(int argc, char *argv[]) {
    return 0;
}
  • return: Finaliza a execução da função atual e retorna um código de status para o chamador ou Sistema Operacional (0 indica sucesso).
    ▶ Ver Exemplo 
    return EXIT_SUCCESS; /* 0 */
  • gcc / clang: Comandos de terminal usados para compilar o código-fonte em um binário executável de alto desempenho.
    ▶ Ver Exemplo 
    gcc -Wall -Wextra -O2 main.c -o servidor

2. Tipos de Dados e Modificadores

  • int: Tipo de dado numérico inteiro (geralmente ocupa 4 bytes em arquiteturas de 32/64 bits).
    ▶ Ver Exemplo 
    int porta = 8080;
  • char: Armazena um único caractere ou byte de informação.
    ▶ Ver Exemplo 
    char metodo = 'G';
  • float e double: Tipos de ponto flutuante para precisão simples (float) e dupla (double).
    ▶ Ver Exemplo 
    float tempo_resposta_ms = 12.45f;
double precisao_medicao = 0.000000012;
  • void: Indica um tipo nulo ou ausência de valor de retorno/parâmetro em funções e ponteiros genéricos.
    ▶ Ver Exemplo 
    void processar_requisicao(void *dados);
  • size_t: Tipo inteiro sem sinal usado especificamente para representar tamanhos em bytes e contagem de memória.
    ▶ Ver Exemplo 
    size_t tamanho_buffer = 1024;
  • unsigned / signed: Modificadores para tipos inteiros que definem a presença ou ausência de sinal negativo.
    ▶ Ver Exemplo 
    unsigned int conexoes_ativas = 500;
  • const: Declara uma variável como somente leitura, impedindo modificações posteriores no código.
    ▶ Ver Exemplo 
    const int MAX_CLIENTES = 1000;
  • volatile: Informa ao compilador que o valor da variável pode ser alterado por fatores externos (hardware, threads, sinais).
    ▶ Ver Exemplo 
    volatile int servidor_rodando = 1;
  • static: Mantém o estado da variável entre chamadas de função ou limita o escopo ao próprio arquivo de tradução.
    ▶ Ver Exemplo 
    static int contador_global_requisicoes = 0;

3. Estruturas de Controle de Fluxo

  • if, else if, else: Estruturas condicionais para desvio do fluxo de execução.
    ▶ Ver Exemplo 
    if (status_code == 200) {
    printf("OK");
} else if (status_code == 404) {
    printf("Not Found");
} else {
    printf("Erro Interno");
}
  • switch, case, default: Seleção múltipla baseada em um valor inteiro ou enum.
    ▶ Ver Exemplo 
    switch (metodo_http) {
    case 1: printf("GET"); break;
    case 2: printf("POST"); break;
    default: printf("Desconhecido"); break;
}
  • while: Laço de repetição com verificação condicional no início.
    ▶ Ver Exemplo 
    while (servidor_ativo) {
    escutar_conexoes();
}
  • do ... while: Laço de repetição garantindo pelo menos uma execução antes da validação da condição.
    ▶ Ver Exemplo 
    do {
    tentar_reconectar();
} while (tentativas < 3);
  • for: Laço de repetição estruturado com inicialização, condição e incremento/decremento.
    ▶ Ver Exemplo 
    for (int i = 0; i < 100; i++) {
    limpar_buffer(i);
}
  • break e continue: Controles de fluxo para interromper abruptamente ou pular para a próxima iteração de um laço.
    ▶ Ver Exemplo 
    for (int i = 0; i < 10; i++) {
    if (i == 2) continue;
    if (i == 5) break;
}
  • goto: Realiza um salto incondicional para um rótulo (label) no código. Muito útil para tratamento unificado de erros em C.
    ▶ Ver Exemplo 
    if (erro) goto cleanup;

cleanup:
    free(buffer);
    return -1;

4. Ponteiros e Alocação Dinâmica de Memória

  • * e &: Operadores de ponteiro. * desreferencia o ponteiro para acessar o valor, e & obtém o endereço de memória de uma variável.
    ▶ Ver Exemplo 
    int valor = 42;
int *ptr = &valor;
printf("Valor: %d", *ptr);
  • sizeof: Operador em tempo de compilação que retorna o tamanho em bytes de um tipo de dado ou estrutura.
    ▶ Ver Exemplo 
    size_t bytes = sizeof(int);
  • malloc(): Aloca dinamicamente um bloco contínuo de memória no Heap sem inicializar seus bytes.
    ▶ Ver Exemplo 
    char *buffer = (char *) malloc(1024 * sizeof(char));
  • calloc(): Aloca memória dinâmica e inicializa automaticamente todos os bytes com zero.
    ▶ Ver Exemplo 
    int *array = (int *) calloc(10, sizeof(int));
  • realloc(): Redimensiona o tamanho de um bloco de memória previamente alocado dinamicamente.
    ▶ Ver Exemplo 
    buffer = (char *) realloc(buffer, 2048);
  • free(): Libera o bloco de memória dinâmica alocado anteriormente no Heap para evitar vazamentos de memória (memory leaks).
    ▶ Ver Exemplo 
    free(buffer);
buffer = NULL;

5. Estruturas, Uniões e Tipos Customizados

  • struct: Agrupa diferentes tipos de dados em uma única estrutura com layout contínuo em memória.
    ▶ Ver Exemplo 
    struct Requisicao {
    int id;
    char path[256];
};
  • typedef: Cria aliases ou apelidos para novos ou existentes tipos de dados.
    ▶ Ver Exemplo 
    typedef struct Requisicao HTTPRequest;
HTTPRequest req;
  • union: Permite armazenar diferentes tipos de dados no mesmo local físico de memória (tamanho determinado pelo maior membro).
    ▶ Ver Exemplo 
    union Payload {
    int inteiro;
    float decimal;
    char texto[4];
};
  • enum: Conjunto de constantes inteiras nomeadas para legibilidade do código.
    ▶ Ver Exemplo 
    typedef enum {
    HTTP_GET,
    HTTP_POST,
    HTTP_DELETE
} HTTPMethod;

6. Manipulação de Strings e Memória

  • strlen(): Calcula o comprimento de uma string C (excluindo o caractere nulo final '\0').
    ▶ Ver Exemplo 
    size_t tam = strlen("HEAD /index.html");
  • strcpy() e strncpy(): Copia bytes de uma string de origem para um destino especificado de forma segura.
    ▶ Ver Exemplo 
    char dest[50];
strncpy(dest, "HTTP/1.1 200 OK", sizeof(dest) - 1);
  • strcmp() e strncmp(): Compara lexicograficamente duas strings byte a byte.
    ▶ Ver Exemplo 
    if (strcmp(metodo, "POST") == 0) {
    /* Processa POST */
}
  • strcat() e strncat(): Concatena uma string no final de outra.
    ▶ Ver Exemplo 
    char caminho[100] = "/var/www";
strncat(caminho, "/index.html", sizeof(caminho) - strlen(caminho) - 1);
  • memset(): Preenche um bloco contínuo de memória com um valor constante específico (muito usado para zera buffers).
    ▶ Ver Exemplo 
    char buffer[1024];
memset(buffer, 0, sizeof(buffer));
  • memcpy() e memmove(): Copia blocos crus de memória de uma região para outra (memmove lida com sobreposição de memória).
    ▶ Ver Exemplo 
    memcpy(destino, origem, tamanho_bytes);

7. Entrada, Saída e Manipulação de Arquivos

  • printf() e scanf(): Funções padrão formatadas de saída no stdout e entrada no stdin.
    ▶ Ver Exemplo 
    printf("Porta ativa: %d\n", porta);
scanf("%d", &porta);
  • snprintf(): Formata e escreve uma string com limite seguro em um buffer especifico (previne buffer overflow).
    ▶ Ver Exemplo 
    char res[128];
snprintf(res, sizeof(res), "HTTP/1.1 %d OK\r\n\r\n", 200);
  • fopen() e fclose(): Abre e fecha um ponteiro para fluxo de arquivo no sistema de arquivos.
    ▶ Ver Exemplo 
    FILE *arq = fopen("log.txt", "a");
/* uso */
fclose(arq);
  • fread() e fwrite(): Lê ou escreve dados binários não formatados em arquivos.
    ▶ Ver Exemplo 
    size_t lidos = fread(buffer, 1, sizeof(buffer), arq);
fwrite(buffer, 1, lidos, arq_saida);
  • fprintf() e fscanf(): Escreve ou lê dados formatados diretamente em fluxos de arquivos (incluindo stderr).
    ▶ Ver Exemplo 
    fprintf(stderr, "Erro crítico ao inicializar socket.\n");
  • fseek() e ftell(): Movimenta o ponteiro interno de posição do arquivo ou retorna sua posição atual em bytes.
    ▶ Ver Exemplo 
    fseek(arq, 0, SEEK_END);
long tam_arquivo = ftell(arq);

8. Diretivas do Pré-Processador

  • #define: Define macros ou constantes simbólicas substituídas antes do processo de compilação real.
    ▶ Ver Exemplo 
    #define BUFFER_SIZE 4096
#define MIN(a,b) ((a) < (b) ? (a) : (b))
  • #ifdef, #ifndef, #endif: Diretivas condicionais de compilação para inclusão/exclusão flexível de código.
    ▶ Ver Exemplo 
    #ifndef MEU_HEADER_H
#define MEU_HEADER_H
/* Conteúdo do Header */
#endif
  • #pragma: Instruções específicas enviadas diretamente ao compilador do sistema.
    ▶ Ver Exemplo 
    #pragma pack(push, 1) /* Evita padding de structs */

9. Sockets e Programação de Redes POSIX (Linux Back-End)

  • socket(): Cria um novo ponto de comunicação de rede e retorna o descritor de arquivo do socket.
    ▶ Ver Exemplo 
    int server_fd = socket(AF_INET, SOCK_STREAM, 0);
  • bind(): Associa o socket a um endereço IP e porta específicos na máquina do servidor.
    ▶ Ver Exemplo 
    struct sockaddr_in addr;
addr.sin_family = AF_INET;
addr.sin_addr.s_addr = INADDR_ANY;
addr.sin_port = htons(8080);
bind(server_fd, (struct sockaddr *)&addr, sizeof(addr));
  • listen(): Coloca o socket no modo passivo de escuta para aguardar conexões de entrada de clientes.
    ▶ Ver Exemplo 
    listen(server_fd, 10); /* Fila máxima de 10 conexões */
  • accept(): Extrai a primeira conexão da fila e cria um novo socket para a comunicação com o cliente conectado.
    ▶ Ver Exemplo 
    int client_fd = accept(server_fd, NULL, NULL);
  • connect(): Inicia a conexão de um socket de cliente com um servidor remoto.
    ▶ Ver Exemplo 
    connect(client_fd, (struct sockaddr *)&addr, sizeof(addr));
  • send() e recv(): Transmite e recebe mensagens por um socket ativo.
    ▶ Ver Exemplo 
    send(client_fd, "HTTP/1.1 200 OK\r\n\r\n", 19, 0);
recv(client_fd, buffer, sizeof(buffer), 0);
  • close(): Fecha um descritor de arquivo ativo (incluindo sockets de rede abertos).
    ▶ Ver Exemplo 
    close(client_fd);
close(server_fd);

10. Concorrência, Processos e Sinais POSIX

  • fork(): Duplica o processo atual, criando um novo processo filho de execução independente.
    ▶ Ver Exemplo 
    pid_t pid = fork();
if (pid == 0) {
    /* Processo filho */
}
  • pthread_create() e pthread_join(): Cria e aguarda a finalização de uma nova Thread POSIX de execução leve.
    ▶ Ver Exemplo 
    pthread_t thread_id;
pthread_create(&thread_id, NULL, tratar_cliente, (void *)&client_fd);
pthread_join(thread_id, NULL);
  • pthread_mutex_init(), lock(), unlock(): Gerencia exclusão mútua (mutex) para proteção de regiões críticas compartilhadas entre threads.
    ▶ Ver Exemplo 
    pthread_mutex_t lock = PTHREAD_MUTEX_INITIALIZER;
pthread_mutex_lock(&lock);
/* Modifica recurso compartilhado */
pthread_mutex_unlock(&lock);
  • signal(): Registra manipuladores (handlers) para capturar interrupções e sinais do SO (como SIGINT do Ctrl+C).
    ▶ Ver Exemplo 
    void tratar_sigint(int sig) {
    printf("Encerrando servidor com segurança...\n");
    exit(0);
}
signal(SIGINT, tratar_sigint);
