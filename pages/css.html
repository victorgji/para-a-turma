CSS3: Regras e Propriedades

Sintaxe Básica

css

seletor {
    propriedade: valor;
    outra-propriedade: valor;
}

1. Regras, Seletores e Diretivas (@rules)

  • Seletores Básicos (Elemento, Classe e ID): Selecionam elementos pelo nome da tag, por classe (.) ou por ID único (#).
    ▶ Ver Exemplo 
    /* Elemento */
p { color: #333; }

/* Classe */
.cartao { background-color: #fff; }

/* ID */
#menu-principal { display: flex; }
  • Combinadores (Descendente, Filho, Adjacente): Definem relações entre elementos na hierarquia HTML.
    ▶ Ver Exemplo 
    /* Descendente */
main p { line-height: 1.5; }

/* Filho Direto (Child) */
ul > li { list-style: none; }

/* Irmão Adjacente */
h2 + p { margin-top: 0; }
  • Pseudoclasses (:hover, :focus, :nth-child): Aplicam estilos com base no estado do elemento ou na sua posição estrutural.
    ▶ Ver Exemplo 
    a:hover { text-decoration: underline; }
input:focus { border-color: #007bff; }
li:nth-child(even) { background-color: #f2f2f2; }
  • Pseudoelementos (::before, ::after): Permitem inserir e estilizar conteúdo fictício antes ou depois do conteúdo real.
    ▶ Ver Exemplo 
    .obrigatorio::after {
  content: " *";
  color: red;
}
  • @media: Regra at-rule usada para criar design responsivo com Media Queries.
    ▶ Ver Exemplo 
    @media (max-width: 768px) {
  .container {
    flex-direction: column;
  }
}
  • @keyframes: Define as etapas e fotogramas para animações complexas em CSS.
    ▶ Ver Exemplo 
    @keyframes surgir {
  from { opacity: 0; transform: translateY(-10px); }
  to { opacity: 1; transform: translateY(0); }
}
  • @import: Importa folhas de estilo externas ou fontes dentro do próprio arquivo CSS.
    ▶ Ver Exemplo 
    @import url('https://fonts.googleapis.com/css2?family=Roboto&display=swap');
  • @font-face: Permite carregar e utilizar fontes personalizadas locais/hospedadas no servidor.
    ▶ Ver Exemplo 
    @font-face {
  font-family: 'MinhaFonte';
  src: url('fonts/minha-fonte.woff2') format('woff2');
}

2. Propriedades de Modelo de Caixa (Box Model) e Display

  • display: Controla o tipo de renderização do elemento na tela (block, inline, flex, grid, etc.).
    ▶ Ver Exemplo 
    .bloco { display: block; }
.inline { display: inline-block; }
.escondido { display: none; }
  • width e height: Definem a largura e a altura do elemento.
    ▶ Ver Exemplo 
    .caixa {
  width: 100%;
  max-width: 1200px;
  height: 300px;
}
  • margin: Controla o espaçamento externo do elemento em relação aos vizinhos.
    ▶ Ver Exemplo 
    .cartao {
  margin: 20px auto; /* 20px acima/abaixo, centralizado nas laterais */
}
  • padding: Controla o espaçamento interno entre a borda do elemento e seu conteúdo.
    ▶ Ver Exemplo 
    .botao {
  padding: 10px 20px;
}
  • box-sizing: Define como a largura e altura totais são calculadas (incluindo ou não padding e border).
    ▶ Ver Exemplo 
    * {
  box-sizing: border-box; /* Garante que padding não aumente o tamanho total */
}
  • border e border-radius: Estiliza a borda e o arredondamento dos cantos.
    ▶ Ver Exemplo 
    .caixa-destaque {
  border: 2px solid #007bff;
  border-radius: 8px;
}

3. Propriedades de Cores e Fundos

  • color: Define a cor do texto do elemento.
    ▶ Ver Exemplo 
    h1 { color: #1a1a1a; }
p { color: rgba(0, 0, 0, 0.8); }
  • background-color: Define a cor de fundo do elemento.
    ▶ Ver Exemplo 
    body { background-color: #f8f9fa; }
  • background-image: Aplica uma imagem ou gradiente como fundo.
    ▶ Ver Exemplo 
    .hero {
  background-image: linear-gradient(to right, #ff7e5f, #feb47b);
}
  • background-size e background-position: Ajustam o tamanho e o posicionamento da imagem de fundo.
    ▶ Ver Exemplo 
    .banner {
  background-image: url('fundo.jpg');
  background-size: cover;
  background-position: center;
}

4. Propriedades de Tipografia e Texto

  • font-family: Especifica a família da fonte a ser utilizada.
    ▶ Ver Exemplo 
    body {
  font-family: 'Roboto', Arial, sans-serif;
}
  • font-size e font-weight: Define o tamanho e a espessura/peso do texto.
    ▶ Ver Exemplo 
    h1 {
  font-size: 2.5rem;
  font-weight: 700;
}
  • text-align: Alinha o texto horizontalmente (left, center, right, justify).
    ▶ Ver Exemplo 
    .titulo-central { text-align: center; }
  • line-height e letter-spacing: Controlam a altura da linha e o espaçamento entre caracteres.
    ▶ Ver Exemplo 
    p {
  line-height: 1.6;
  letter-spacing: 0.5px;
}
  • text-decoration: Controla o estilo decorativo do texto (como sublinhado ou risco).
    ▶ Ver Exemplo 
    a { text-decoration: none; }
.descontado { text-decoration: line-through; }

5. Layout: Flexbox e Grid

  • flex-direction, justify-content e align-items: Controlam o fluxo e o alinhamento de itens no container Flexbox.
    ▶ Ver Exemplo 
    .container-flex {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
}
  • flex-wrap e gap: Permite que os itens dobrem de linha e define o espaçamento interno entre eles.
    ▶ Ver Exemplo 
    .galeria {
  display: flex;
  flex-wrap: wrap;
  gap: 16px;
}
  • grid-template-columns e grid-template-rows: Define a estrutura de colunas e linhas no CSS Grid Layout.
    ▶ Ver Exemplo 
    .grade {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

6. Posicionamento e Camadas

  • position: Define a estratégia de posicionamento (static, relative, absolute, fixed, sticky).
    ▶ Ver Exemplo 
    .menu-fixo {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
}
  • top, right, bottom, left: Determina o deslocamento para elementos posicionados.
    ▶ Ver Exemplo 
    .badge {
  position: absolute;
  top: -10px;
  right: -10px;
}
  • z-index: Controla a ordem de empilhamento vertical (profundidade) dos elementos.
    ▶ Ver Exemplo 
    .modal {
  position: fixed;
  z-index: 9999;
}

7. Animações, Transições e Efeitos Visuals

  • transition: Cria uma animação suave entre mudanças de propriedades CSS (ex: no hover).
    ▶ Ver Exemplo 
    .botao {
  background-color: #007bff;
  transition: background-color 0.3s ease-in-out;
}
.botao:hover { background-color: #0056b3; }
  • transform: Aplica transformações 2D ou 3D (rotacionar, escalar, transladar).
    ▶ Ver Exemplo 
    .cartao:hover {
  transform: translateY(-5px) scale(1.02);
}
  • animation: Associa uma regra @keyframes ao elemento especificando duração e repetição.
    ▶ Ver Exemplo 
    .carregando {
  animation: surgir 1s ease-in-out infinite alternate;
}
  • box-shadow e text-shadow: Adiciona efeitos de sombra a caixas ou textos.
    ▶ Ver Exemplo 
    .card {
  box-shadow: 0 4px 8px rgba(0, 0, 0, 0.1);
}
  • opacity e filter: Controla a transparência e aplica efeitos visuais (blur, grayscale, etc.).
    ▶ Ver Exemplo 
    .foto-antiga {
  opacity: 0.8;
  filter: grayscale(100%);
}
