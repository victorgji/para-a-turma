1. Palavras-Chave, Variáveis e Declarações

  • var: Declara uma variável de escopo global ou de função, permitindo reatribuição e sofrendo hoisting (inicializada como undefined).
    ▶ Ver Exemplo 
    var nome = "Maria";
    var nome = "Ana"; // Permitido
    console.log(nome);
  • let: Declara uma variável com escopo de bloco, permitindo reatribuição, mas sem sofrer hoisting acessível antes da declaração (ReferenceError).
    ▶ Ver Exemplo 
    let idade = 25;
    idade = 26; // Permitido
    // let idade = 30; // Erro de sintaxe (redeclaração)
  • const: Declara uma constante com escopo de bloco cujo valor não pode ser reatribuído (o valor em si é imutável, mas objetos/arrays internos podem ter propriedades mutadas).
    ▶ Ver Exemplo 
    const PI = 3.14159;
    // PI = 3.14; // Erro!
    const usuario = { nome: "Carlos" };
    usuario.nome = "Roberto"; // Permitido (mutação de propriedade)
  • function / return: Define uma função tradicional e especifica o valor de retorno da execução.
    ▶ Ver Exemplo 
    function somar(a, b) {
        return a + b;
    }
    console.log(somar(2, 3)); // 5
  • class / constructor / extends / super: Sintaxe de orientação a objetos baseada em protótipos para criação de classes e herança.
    ▶ Ver Exemplo 
    class Animal {
        constructor(nome) { this.nome = nome; }
        falar() { return `${this.nome} emite som.`; }
    }
    class Cachorro extends Animal {
        falar() { return `${this.nome} late.`; }
    }
    const dog = new Cachorro("Rex");
    console.log(dog.falar());
  • this: Palavra-chave contextual que aponta para o objeto que está executando o contexto atual.
    ▶ Ver Exemplo 
    const pessoa = {
        nome: "Julia",
        dizerNome() { return this.nome; }
    };
    console.log(pessoa.dizerNome()); // Julia
  • new: Cria uma instância de um objeto construído por uma função construtora ou classe.
    ▶ Ver Exemplo 
    const dataAtual = new Date();
    console.log(dataAtual.getFullYear());
  • delete: Remove uma propriedade de um objeto ou um elemento de um array (deixando um espaço vazio/undefined).
    ▶ Ver Exemplo 
    const obj = { x: 1, y: 2 };
    delete obj.x;
    console.log(obj.x); // undefined
  • typeof / instanceof: Operadores para verificar o tipo de dado de um operando ou se um objeto é instância de uma classe/construtor.
    ▶ Ver Exemplo 
    console.log(typeof 123); // "number"
    console.log([] instanceof Array); // true
  • void: Avalia a expressão fornecida e retorna undefined.
    ▶ Ver Exemplo 
    let resultado = void (5 + 5);
    console.log(resultado); // undefined
  • debugger: Aciona uma instrução de depuração, pausando a execução se houver ferramentas de desenvolvimento abertas.
    ▶ Ver Exemplo 
    function debugarCodigo() {
        debugger; // Pausa aqui no browser
    }

2. Tipos de Dados e Operadores

  • Tipos Primitivos (String, Number, Boolean, Undefined, Null, Symbol, BigInt): Valores imutáveis fundamentais.
    ▶ Ver Exemplo 
    let str = "Texto";
    let num = 42;
    let bool = true;
    let indef = undefined;
    let nulo = null;
    let sym = Symbol("id");
    let big = 9007199254740991n;
  • Template Literals (`...${}`): Strings delimitadas por crases que permitem interpolação de variáveis e quebras de linha nativas.
    ▶ Ver Exemplo 
    const nome = "Carlos";
    console.log(`Olá, ${nome}! 
    Seja bem-vindo.`);
  • Operadores Aritméticos (+, -, *, /, %, **, ++, --): Executam operações matemáticas e incrementos/decrementos.
    ▶ Ver Exemplo 
    let exp = 2 ** 3; // 8 (potenciação)
    let mod = 10 % 3; // 1 (resto da divisão)
    let x = 5; x++; // x vira 6
  • Operadores de Atribuição (=, +=, -=, *=, /=, ??=, etc.): Atribuem valores com operações combinadas.
    ▶ Ver Exemplo 
    let total = 10;
    total += 5; // total = 15
    let config = null;
    config ??= "padrao"; // Atribui se for null/undefined
  • Operadores de Comparação e Igualdade (==, ===, !=, !==, >, <, >=, <=): Comparam valores com ou sem coerção de tipo estrita.
    ▶ Ver Exemplo 
    console.log(5 == "5");  // true (compara valor)
    console.log(5 === "5"); // false (compara valor e tipo)
  • Operadores Lógicos (&&, ||, !): Conectam expressões booleanas (E lógico, OU lógico, Negação).
    ▶ Ver Exemplo 
    let logado = true;
    let admin = false;
    console.log(logado && admin); // false
    console.log(!logado); // false
  • Nullish Coalescing (??) e Optional Chaining (?.): Retorna o operando direito se o esquerdo for null/undefined; o encadeamento opcional previne erros em propriedades nulas.
    ▶ Ver Exemplo 
    const user = { perfil: { nome: "Ana" } };
    console.log(user.endereco?.rua); // undefined (sem erro)
    let valor = null ?? "Fallback"; // "Fallback"
  • Operador Ternário (condicao ? verdadeiro : falso): Atalho condicional inline.
    ▶ Ver Exemplo 
    const idade = 18;
    const status = idade >= 18 ? "Maior de idade" : "Menor de idade";
  • Spread (...) e Destructuring (Desestruturação): Espalham elementos de iteráveis ou extraem propriedades de objetos e arrays facilmente.
    ▶ Ver Exemplo 
    const arr1 = [1, 2];
    const arr2 = [...arr1, 3, 4]; // [1, 2, 3, 4]
    const { nome } = { nome: "Lucas", idade: 30 };

3. Estruturas de Controle e Fluxo

  • if / else if / else: Condicionais tradicionais para desvios de fluxo baseados em expressões booleanas.
    ▶ Ver Exemplo 
    let nota = 8;
    if (nota >= 7) {
        console.log("Aprovado");
    } else {
        console.log("Reprovado");
    }
  • switch / case / default / break: Avalia uma expressão comparando com múltiplos valores de caso.
    ▶ Ver Exemplo 
    let dia = "Segunda";
    switch (dia) {
        case "Segunda": console.log("Início da semana"); break;
        default: console.log("Outro dia");
    }
  • for / for...in / for...of: Loops para iteração clássica de índices, chaves de objetos ou valores de iteráveis.
    ▶ Ver Exemplo 
    for (let i = 0; i < 3; i++) { console.log(i); }
    const nums = [10, 20];
    for (let val of nums) { console.log(val); }
  • while / do...while: Loops executados enquanto a condição for verdadeira (o segundo executa ao menos uma vez).
    ▶ Ver Exemplo 
    let contador = 0;
    while (contador < 2) {
        console.log(contador);
        contador++;
    }
  • break / continue / label: Interrompem um loop inteiro ou pulam para a próxima iteração.
    ▶ Ver Exemplo 
    for (let i = 0; i < 5; i++) {
        if (i === 2) continue; // Pula o 2
        if (i === 4) break;    // Para no 4
        console.log(i);
    }

4. Funções, Escopo e Closures

  • Arrow Functions (() => {}): Sintaxe reduzida para funções, que preservam o escopo léxico do this.
    ▶ Ver Exemplo 
    const multiplicar = (a, b) => a * b;
    console.log(multiplicar(3, 4)); // 12
  • Parâmetros Rest (...args) e Parâmetros Padrão: Permitem receber argumentos indefinidos em um array ou definir valores default.
    ▶ Ver Exemplo 
    function somarTudo(...numeros) {
        return numeros.reduce((acc, n) => acc + n, 0);
    }
    console.log(somarTudo(1, 2, 3, 4)); // 10
  • Closures: Função interna que retém o acesso ao escopo de sua função externa mesmo após esta ter retornado.
    ▶ Ver Exemplo 
    function criarContador() {
        let count = 0;
        return () => ++count;
    }
    const incrementar = criarContador();
    console.log(incrementar()); // 1
    console.log(incrementar()); // 2
  • IIFE (Immediately Invoked Function Expression): Função executada imediatamente após sua definição.
    ▶ Ver Exemplo 
    (function() {
        console.log("Executado imediatamente!");
    })();

5. Objetos Globais e Métodos Nativos (Math, Date, Array, String, JSON, Object)

  • Array (Métodos avançados: map, filter, reduce, find, some, every, flat): Manipulação funcional de listas.
    ▶ Ver Exemplo 
    const numeros = [1, 2, 3, 4];
    const dobrados = numeros.map(n => n * 2);
    const pares = numeros.filter(n => n % 2 === 0);
    console.log(dobrados, pares);
  • String e Number: Métodos utilitários de manipulação de texto e conversão numérica.
    ▶ Ver Exemplo 
    let texto = "  Frontend  ";
    console.log(texto.trim().toUpperCase()); // "FRONTEND"
    console.log(Number.parseInt("10px")); // 10
  • Math e Date: Objeto de operações matemáticas avançadas e manipulação de datas temporais.
    ▶ Ver Exemplo 
    console.log(Math.floor(Math.random() * 10) + 1); // 1 a 10
    const hoje = new Date();
    console.log(hoje.toISOString());
  • JSON (JSON.stringify / JSON.parse): Conversão entre objetos JavaScript e strings formato JSON.
    ▶ Ver Exemplo 
    const obj = { x: 10, y: "texto" };
    const jsonString = JSON.stringify(obj);
    const objetoRecuperado = JSON.parse(jsonString);
  • Object (keys, values, entries, assign): Métodos estáticos para inspecionar e clonar objetos.
    ▶ Ver Exemplo 
    const usuario = { nome: "Carla", idade: 28 };
    console.log(Object.keys(usuario)); // ["nome", "idade"]
    console.log(Object.entries(usuario)); // [["nome", "Carla"], ["idade", 28]]

6. Manipulação do DOM e Sistema de Eventos

  • Seleção de Elementos (document.getElementById, querySelector, querySelectorAll): Encontra nós na árvore do DOM.
    ▶ Ver Exemplo 
    const tituloPrincipal = document.querySelector("h1");
    const itensLista = document.querySelectorAll("li");
  • Modificação de Conteúdo e Atributos (textContent, innerHTML, setAttribute, classList): Altera dinamicamente a página.
    ▶ Ver Exemplo 
    const div = document.createElement("div");
    div.textContent = "Olá Mundo";
    div.classList.add("destaque", "visivel");
    document.body.appendChild(div);
  • addEventListener / removeEventListener: Registra ouvintes de eventos interativos do usuário (cliques, inputs, teclas).
    ▶ Ver Exemplo 
    const btn = document.querySelector("#meuBotao");
    btn.addEventListener("click", (evento) => {
        console.log("Botão clicado nas coordenadas:", evento.clientX, evento.clientY);
    });
  • Event Bubbling, Capturing e Event Delegation: Propagação de eventos na árvore DOM e delegação para elementos pais.
    ▶ Ver Exemplo 
    document.body.addEventListener("click", (e) => {
        if (e.target.matches("button")) {
            console.log("Botão dinâmico acionado via delegação!");
        }
    });

7. Assincronicidade (Callbacks, Promises, Async/Await)

  • setTimeout e setInterval: Funções da Web API para agendamento de tarefas assíncronas no Event Loop.
    ▶ Ver Exemplo 
    const timerId = setTimeout(() => {
        console.log("Executado após 2 segundos");
    }, 2000);
    clearTimeout(timerId); // Cancela o timer
  • Promise (resolve, reject, then, catch, finally): Representa a eventual conclusão ou falha de uma operação assíncrona.
    ▶ Ver Exemplo 
    const promessa = new Promise((resolve, reject) => {
        let sucesso = true;
        if (sucesso) resolve("Dados carregados!");
        else reject("Erro na operação.");
    });
    promessa.then(res => console.log(res)).catch(err => console.error(err));
  • Promise.all, Promise.race, Promise.allSettled, Promise.any: Métodos combinadores de múltiplas promessas simultâneas.
    ▶ Ver Exemplo 
    Promise.all([
        Promise.resolve("A"),
        Promise.resolve("B")
    ]).then(resultados => console.log(resultados)); // ["A", "B"]
  • async / await: Sintaxe elegante construída sobre Promises para escrever código assíncrono que parece síncrono.
    ▶ Ver Exemplo 
    async function buscarDados() {
        try {
            let resposta = await fetch("https://api.exemplo.com/dados");
            let dados = await resposta.json();
            console.log(dados);
        } catch (erro) {
            console.error("Falha ao buscar:", erro);
        }
    }
    buscarDados();

8. Módulos, Tratamento de Erros e Programação Defensiva

  • import / export (Named & Default): Sistema de módulos ES6 para modularização e reuso de código entre arquivos.
    ▶ Ver Exemplo 
    // modulo.js
    export const PI = 3.14;
    export default function saudacao() { return "Olá"; }

    // main.js
    import saudacao, { PI } from './modulo.js';
  • try / catch / finally / throw: Tratamento robusto de exceções em tempo de execução.
    ▶ Ver Exemplo 
    function dividir(a, b) {
        if (b === 0) throw new Error("Divisão por zero não permitida");
        return a / b;
    }
    try {
        dividir(10, 0);
    } catch (e) {
        console.error(e.message);
    } finally {
        console.log("Bloco final executado.");
    }
  • use strict: Modo estrito que ativa restrições severas de parsing e tratamento de erros silenciosos no JavaScript.
    ▶ Ver Exemplo 
    "use strict";
    // variavelGlobalNaoDeclarada = 10; // Erro imediato no strict mode

9. APIs do Navegador Relevantes para Front-End

  • Fetch API (fetch()): Interface nativa para requisições HTTP assíncronas via rede (GET, POST, PUT, DELETE).
    ▶ Ver Exemplo 
    fetch('https://jsonplaceholder.typicode.com/todos/1')
        .then(response => response.json())
        .then(json => console.log(json));
  • Web Storage (localStorage / sessionStorage): Persistência de dados chave-valor no navegador do cliente.
    ▶ Ver Exemplo 
    localStorage.setItem('usuario', 'Carlos');
    let user = localStorage.getItem('usuario');
    localStorage.removeItem('usuario');
  • Geolocation API (navigator.geolocation): Permite acessar a posição geográfica do usuário com permissão.
    ▶ Ver Exemplo 
    if ('geolocation' in navigator) {
        navigator.geolocation.getCurrentPosition(pos => {
            console.log("Lat:", pos.coords.latitude, "Lon:", pos.coords.longitude);
        });
    }
  • History API (history.pushState, history.replaceState): Manipula o histórico de navegação do browser para Single Page Applications (SPAs).
    ▶ Ver Exemplo 
    history.pushState({page: 1}, "Título", "/perfil");
