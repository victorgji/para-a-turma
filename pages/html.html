HTML5: Estrutura Básica e Tags

Estrutura Básica

html

<!DOCTYPE html>
<html lang="pt-br">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Título da Página</title>
    </head>
    <body>
        <!-- você sabe o que vem aqui -->
    </body>
</html>

1. Estrutura Básica e Metadados

  • <!DOCTYPE html>: Declaração obrigatória que avisa o navegador que a página utiliza a versão mais recente do HTML (HTML5).
    ▶ Ver Exemplo 
    <!DOCTYPE html>
  • <html>: A tag raiz que envolve todo o conteúdo da página. O atributo lang="pt-br" define o idioma principal.
    ▶ Ver Exemplo 
    <html lang="pt-br">
  <!-- Todo o conteúdo do site entra aqui -->
</html>
  • <head>: Contêiner que guarda os metadados (informações sobre o documento) que não aparecem diretamente para o usuário.
    ▶ Ver Exemplo 
    <head>
  <meta charset="UTF-8">
  <title>Configurações Internas</title>
</head>
  • <title>: Define o título da página que aparece na aba do navegador e nos resultados de busca.
    ▶ Ver Exemplo 
    <title>Meu Portfólio | Home</title>
  • <meta>: Define metadados como codificação de caracteres (charset="UTF-8"), configurações de viewport para responsividade, autor e descrição.
    ▶ Ver Exemplo 
    <meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Guia completo de tags HTML5">
  • <link>: Usada para conectar o documento a recursos externos, mais frequentemente folhas de estilo CSS (.css) ou favicons.
    ▶ Ver Exemplo 
    <link rel="stylesheet" href="styles.css">
<link rel="icon" href="favicon.ico" type="image/x-icon">
  • <style>: Permite inserir regras de estilo CSS diretamente dentro do documento HTML.
    ▶ Ver Exemplo 
    <style>
  body { background-color: #fafafa; color: #333; }
</style>
  • <script>: Usada para incorporar ou referenciar códigos JavaScript externos ou internos.
    ▶ Ver Exemplo 
    <script src="app.js" defer></script>
<script>
  console.log('Código interno rodando!');
</script>
  • <noscript>: Define um conteúdo alternativo para ser exibido caso o navegador do usuário esteja com o JavaScript desativado.
    ▶ Ver Exemplo 
    <noscript>
  <p>Este site precisa de JavaScript para funcionar corretamente.</p>
</noscript>
  • <body>: Contém todo o conteúdo visível da página (textos, imagens, links, vídeos, etc.).
    ▶ Ver Exemplo 
    <body>
  <h1>Conteúdo Visível da Página</h1>
</body>

2. Estrutura Semântica de Layout

  • <header>: Define o cabeçalho de uma página ou de uma seção específica. Geralmente contém logos e menus de navegação.
    ▶ Ver Exemplo 
    <header>
  <img src="logo.png" alt="Logo da Empresa">
  <h1>Nome do Site</h1>
</header>
  • <nav>: Bloco que agrupa links de navegação principal do site.
    ▶ Ver Exemplo 
    <nav>
  <a href="home.html">Home</a> | 
  <a href="sobre.html">Sobre</a> | 
  <a href="contato.html">Contato</a>
</nav>
  • <main>: Define o conteúdo principal e exclusivo da página. Só deve existir um por página.
    ▶ Ver Exemplo 
    <main>
  <h2>Seção Principal do Artigo</h2>
  <p>Conteúdo exclusivo desta URL.</p>
</main>
  • <article>: Representa um conteúdo autônomo e independente que faz sentido por si só (ex: um post de blog, uma notícia).
    ▶ Ver Exemplo 
    <article>
  <h2>Novidades do HTML5</h2>
  <p>Postado por João em 2026. O HTML5 trouxe melhorias...</p>
</article>
  • <section>: Define uma seção genérica de conteúdo temático dentro de uma página.
    ▶ Ver Exemplo 
    <section>
  <h3>Nossos Serviços</h3>
  <p>Oferecemos desenvolvimento web completo.</p>
</section>
  • <aside>: Define um conteúdo tangencial ou secundário (como barras laterais, anúncios ou caixas de curiosidades).
    ▶ Ver Exemplo 
    <aside>
  <h4>Anúncios Relacionados</h4>
  <p>Confira nossa loja de hospedagem!</p>
</aside>
  • <footer>: Define o rodapé de uma página ou de uma seção (geralmente contém direitos autorais e contatos).
    ▶ Ver Exemplo 
    <footer>
  <p>&copy; 2026 Todos os direitos reservados.</p>
</footer>
  • <address>: Fornece informações de contato para a pessoa ou organização dona do site ou do artigo.
    ▶ Ver Exemplo 
    <address>
  E-mail: <a href="mailto:suporte@site.com">suporte@site.com</a><br>
  Rua Central, nº 100 - Centro
</address>

3. Conteúdo Textual e Organização

  • <div>: Um contêiner genérico em bloco (block-level) usado para agrupar elementos para fins de estilização (CSS) ou script. Não tem significado semântico.
    ▶ Ver Exemplo 
    <div class="card-box">
  <p>Texto dentro de uma caixa estrutural genérica.</p>
</div>
  • <span>: Um contêiner genérico em linha (inline) usado para aplicar styles ou scripts a partes específicas de um texto.
    ▶ Ver Exemplo 
    <p>Este texto possui uma palavra <span style="color:red;">vermelha</span>.</p>
  • <p>: Define um parágrafo de texto.
    ▶ Ver Exemplo 
    <p>Este é o primeiro parágrafo de conteúdo.</p>
  • <h1> a <h6>: Títulos e subtítulos da página, onde h1 é o mais importante e h6 o de menor importância.
    ▶ Ver Exemplo 
    <h1>Título Principal (SEO Principal)</h1>
<h2>Subtítulo Importante</h2>
<h3>Sub-seção menor</h3>
  • <hr>: Cria uma quebra temática ou uma linha horizontal divisória.
    ▶ Ver Exemplo 
    <p>Assunto de cima</p>
<hr>
<p>Novo assunto de baixo</p>
  • <br>: Produz uma quebra de linha simples no texto.
    ▶ Ver Exemplo 
    Primeira Linha.<br>Segunda Linha logo abaixo.
  • <pre>: Exibe o texto exatamente como foi digitado no código, preservando espaços em branco e quebras de linha.
    ▶ Ver Exemplo 
    <pre>
    Espaçado
       com recuo manual.
</pre>
  • <blockquote>: Usada para indicar uma citação longa de outra fonte, geralmente recuada.
    ▶ Ver Exemplo 
    <blockquote cite="https://site.com">
  "O único modo de fazer um bom trabalho é amar o que você faz."
</blockquote>

4. Listas

  • <ul>: Define uma lista não ordenada (geralmente com marcadores de bolinha).
    ▶ Ver Exemplo 
    <ul>
  <li>Maçã</li>
  <li>Banana</li>
</ul>
  • <ol>: Define uma lista ordenada (numerada ou sequencial).
    ▶ Ver Exemplo 
    <ol>
  <li>Primeiro Passo</li>
  <li>Segundo Passo</li>
</ol>
  • <li>: Define um item de uma lista (usado dentro de ul ou ol).
    ▶ Ver Exemplo 
    <li>Item avulso (requer ul ou ol externo)</li>
  • <dl>: Define uma lista de descrição (termos e suas respectivas descrições).
    ▶ Ver Exemplo 
    <dl>
  <dt>Café</dt>
  <dd>Bebida preta quente feita de grãos torrados.</dd>
</dl>
  • <dt>: Define o termo a ser descrito dentro de uma lista de descrição (dl).
    ▶ Ver Exemplo 
    <dt>HTML</dt>
  • <dd>: Define a descrição ou definição do termo anterior (dt).
    ▶ Ver Exemplo 
    <dd>Linguagem de marcação de hipertexto.</dd>

5. Semântica de Texto (Formatação Interna)

  • <a>: Cria um hiperlink para outras páginas, arquivos ou seções da mesma página utilizando o atributo href.
    ▶ Ver Exemplo 
    <a href="https://www.google.com" target="_blank">Ir para o Google</a>
  • <strong>: Indica que o texto tem forte importância ou urgência. Por padrão, o navegador o exibe em negrito.
    ▶ Ver Exemplo 
    Atenção: Esse campo é <strong>obrigatório</strong>!
  • <em>: Enfatiza uma palavra ou trecho, mudando o sentido da frase. Por padrão, o navegador o exibe em itálico.
    ▶ Ver Exemplo 
    Eu <em>realmente</em> preciso terminar isso hoje.
  • <small>: Representa comentários laterais ou "letras miúdas" (como avisos legais ou direitos autorais).
    ▶ Ver Exemplo 
    <p>Preço: R$ 10,00 <small>(Sujeito a taxas locais)</small></p>
  • <s>: Indica que o texto não é mais correto, relevante ou preciso (renderiza um risco no meio do texto).
    ▶ Ver Exemplo 
    De <s>R$ 99,00</s> por apenas R$ 49,00!
  • <cite>: Define o título de uma obra de arte, livro, música ou filme que está sendo citado.
    ▶ Ver Exemplo 
    Estou lendo <cite>Dom Casmurro</cite> de Machado de Assis.
  • <q>: Usada para citações textuais curtas em linha (o navegador adiciona as aspas automaticamente).
    ▶ Ver Exemplo 
    Ele olhou para trás e disse: <q>Estou voltando em breve</q>.
  • <dfn>: Indica o termo que está sendo definido dentro do contexto do texto.
    ▶ Ver Exemplo 
    O <dfn>CSS</dfn> é uma linguagem de estilo utilizada para páginas web.
  • <abbr>: Define uma abreviação ou sigla (o atributo title mostra a definição ao passar o mouse).
    ▶ Ver Exemplo 
    A <abbr title="Organização das Nações Unidas">ONU</abbr> declarou paz.
  • <data>: Associa um conteúdo legível por humanos a um valor legível por máquinas.
    ▶ Ver Exemplo 
    Temos a <data value="P-103">Camiseta Preta</data> em estoque.
  • <time>: Representa uma data ou hora específica no calendário.
    ▶ Ver Exemplo 
    O concerto começa às <time datetime="20:00">20h</time> do dia <time datetime="2026-07-07">07 de julho</time>.
  • <code>: Usada para exibir fragmentos de código de computador.
    ▶ Ver Exemplo 
    Use a função <code>querySelector()</code> do JavaScript.
  • <var>: Define uma variável em uma expressão matemática ou de programação.
    ▶ Ver Exemplo 
    Na equação <var>x</var> + 5 = 10, o valor de <var>x</var> é 5.
  • <samp>: Representa a saída (output) de um programa de computador ou sistema.
    ▶ Ver Exemplo 
    O terminal retornou: <samp>Error 404: Not Found</samp>.
  • <kbd>: Indica uma entrada do usuário, geralmente teclas do teclado.
    ▶ Ver Exemplo 
    Pressione <kbd>Ctrl</kbd> + <kbd>C</kbd> para copiar.
  • <sub>: Formata o texto como subscrito (abaixo da linha).
    ▶ Ver Exemplo 
    A fórmula molecular da água é H<sub>2</sub>O.
  • <sup>: Formata o texto como sobrescrito (acima da linha).
    ▶ Ver Exemplo 
    A equação de Einstein é E = mc<sup>2</sup>.
  • <i>: Usada para termos técnicos, pensamentos ou palavras em outros idiomas (renderiza em itálico).
    ▶ Ver Exemplo 
    O termo <i>Homo sapiens</i> refere-se à espécie humana.
  • <b>: Usada para chamar atenção para o texto sem dar importância extra (renderiza em negrito).
    ▶ Ver Exemplo 
    As primeiras palavras do parágrafo estão em <b>destaque visual</b>.
  • <u>: Renderiza o texto com uma linha sublinhada.
    ▶ Ver Exemplo 
    Esse texto contém um erro de <u>ortografia</u>.
  • <mark>: Destaca ou realça um texto (efeito de caneta marca-texto).
    ▶ Ver Exemplo 
    Informação extremamente <mark>importante</mark> para a prova.
  • <ruby>, <rt>, <rp>: Usada para exibir anotações tipográficas (pronúncias) em caracteres orientais.
    ▶ Ver Exemplo 
    <ruby>
  漢 <rp>(</rp><rt>kan</rt><rp>)</rp>
</ruby>
  • <bdi>: Isola um trecho de texto que pode estar formatado em uma direção de leitura diferente (útil em textos bi-direcionais como Árabe).
    ▶ Ver Exemplo 
    Nome do Usuário: <bdi>إيان</bdi> - Postado há 5 minutos.
  • <bdo>: Força a direção de renderização do texto de forma explícita.
    ▶ Ver Exemplo 
    <bdo dir="rtl">Este texto será lido de trás para frente.</bdo>
  • <ins>: Representa um texto que foi inserido/adicionado ao documento.
    ▶ Ver Exemplo 
    O preço do plano atual é de <ins>R$ 29,90/mês</ins>.
  • <del>: Representa um texto que foi deletado/removido do documento.
    ▶ Ver Exemplo 
    O preço antigo era de <del>R$ 49,90/mês</del>.

6. Elementos Multimídia

  • <img>: Incorpora uma imagem na página através do atributo src.
    ▶ Ver Exemplo 
    <img src="foto.jpg" alt="Foto da paisagem das montanhas no inverno" width="400">
  • <iframe>: Incorpora uma outra página HTML dentro da página atual.
    ▶ Ver Exemplo 
    <iframe src="https://maps.google.com" width="600" height="400"></iframe>
  • <embed>: Contêiner para integração de aplicações externas ou conteúdos interativos de terceiros.
    ▶ Ver Exemplo 
    <embed type="video/webm" src="animacao.webm" width="300" height="200">
  • <object>: Um contêiner genérico para recursos externos (como plugins, PDFs ou imagens).
    ▶ Ver Exemplo 
    <object data="manual.pdf" type="application/pdf" width="100%" height="500px">
  <p>Seu navegador não suporta a visualização nativa de PDFs.</p>
</object>
  • <param>: Define parâmetros adicionais para a tag object.
    ▶ Ver Exemplo 
    <object data="jogo.swf">
  <param name="autoplay" value="true">
</object>
  • <video>: Incorpora um reprodutor de vídeo nativo na página.
    ▶ Ver Exemplo 
    <video controls width="500">
  <source src="filme.mp4" type="video/mp4">
  Seu navegador não suporta vídeos HTML5.
</video>
  • <audio>: Incorpora um reprodutor de áudio nativo na página.
    ▶ Ver Exemplo 
    <audio controls>
  <source src="musica.mp3" type="audio/mpeg">
</audio>
  • <source>: Especifica múltiplos recursos de mídia para as tags video, audio ou picture.
    ▶ Ver Exemplo 
    <source src="audio.ogg" type="audio/ogg">
  • <track>: Define faixas de texto cronometradas (como legendas) para vídeos ou áudios.
    ▶ Ver Exemplo 
    <video src="video.mp4" controls>
  <track src="legendas_pt.vtt" kind="subtitles" srclang="pt" label="Português" default>
</video>
  • <picture>: Permite oferecer diferentes versões de uma imagem dependendo do tamanho da tela.
    ▶ Ver Exemplo 
    <picture>
  <source media="(min-width: 800px)" srcset="banner-grande.jpg">
  <source media="(min-width: 450px)" srcset="banner-medio.jpg">
  <img src="banner-celular.jpg" alt="Banner Responsivo">
</picture>
  • <canvas>: Cria uma área gráfica onde desenhos e animações podem ser renderizados via JavaScript.
    ▶ Ver Exemplo 
    <canvas id="quadroDesenho" width="200" height="200"></canvas>
  • <svg>: Usado para desenhar gráficos vetoriais diretamente no HTML.
    ▶ Ver Exemplo 
    <svg width="100" height="100">
  <circle cx="50" cy="50" r="40" stroke="green" stroke-width="4" fill="yellow" />
</svg>
  • <map> e <area>: Define um mapa de imagem interativo com regiões mapeadas clicáveis.
    ▶ Ver Exemplo 
    <img src="mapa.jpg" usemap="#meumap">
<map name="meumap">
  <area shape="rect" coords="0,0,50,50" alt="Botão Quadrado" href="link1.html">
</map>

7. Tabelas

  • <table>: Declara e envolve uma tabela de dados.
    ▶ Ver Exemplo 
    <table border="1">
  <!-- Estrutura interna de linhas e colunas -->
</table>
  • <caption>: Define o título ou legenda da tabela.
    ▶ Ver Exemplo 
    <caption>Tabela de Preços e Modelos</caption>
  • <thead>, <tbody>, <tfoot>: Setores de divisão lógica (Cabeçalho, Corpo e Rodapé da tabela).
    ▶ Ver Exemplo 
    <table>
  <thead><tr><th>Produto</th></tr></thead>
  <tbody><tr><td>Teclado</td></tr></tbody>
  <tfoot><tr><td>Total: 1</td></tr></tfoot>
</table>
  • <tr>, <th>, <td>: Linha (row), Célula de Cabeçalho (Header cell) e Célula Comum de Dados (Data cell).
    ▶ Ver Exemplo 
    <tr>
  <th>Coluna Título</th>
  <td>Dado da Célula</td>
</tr>
  • <colgroup> e <col>: Agrupa colunas para aplicar estilos estruturais de uma só vez.
    ▶ Ver Exemplo 
    <colgroup>
  <col span="2" style="background-color: #f2f2f2">
</colgroup>

8. Formulários e Interatividade

  • <form>: Define um formulário para coleta de dados enviados pelo usuário.
    ▶ Ver Exemplo 
    <form action="/processar_cadastro" method="POST">
  <!-- Campos de entrada entram aqui -->
</form>
  • <label>: Cria uma etiqueta de texto vinculada a um elemento específico do formulário.
    ▶ Ver Exemplo 
    <label for="emailUsuario">E-mail:</label>
<input type="email" id="emailUsuario">
  • <input>: Cria campos variados de entrada de dados (texto, senhas, e-mails, botões).
    ▶ Ver Exemplo 
    <input type="text" placeholder="Nome Completo">
<input type="password" placeholder="Sua Senha">
  • <button>: Cria um botão clicável para submissão ou ações na página.
    ▶ Ver Exemplo 
    <button type="submit">Salvar Cadastro</button>
  • <select>, <optgroup>, <option>: Cria menus dropdown estruturados e selecionáveis.
    ▶ Ver Exemplo 
    <select name="carros">
  <optgroup label="Nacionais">
    <option value="gol">Gol</option>
  </optgroup>
</select>
  • <textarea>: Cria uma caixa de digitação longa de múltiplas linhas.
    ▶ Ver Exemplo 
    <textarea name="mensagem" rows="4" cols="40">Deixe sua opinião...</textarea>
  • <fieldset> e <legend>: Agrupa visualmente blocos de inputs semelhantes e define um cabeçalho.
    ▶ Ver Exemplo 
    <fieldset>
  <legend>Endereço de Entrega</legend>
  <input type="text" placeholder="CEP">
</fieldset>
  • <datalist>: Cria uma lista interna de auto-sugestões vinculada a um campo `input`.
    ▶ Ver Exemplo 
    <input list="navegadores">
<datalist id="navegadores">
  <option value="Chrome">
  <option value="Firefox">
</datalist>
  • <output>: Mostra o resultado visível direto de um cálculo de script efetuado.
    ▶ Ver Exemplo 
    <output name="resultadoCalculo">100</output>
  • <progress>: Exibe uma barra nativa de progresso de download/upload.
    ▶ Ver Exemplo 
    <progress value="70" max="100">70%</progress>
  • <meter>: Exibe de forma gráfica uma medida escalar estática dentro de uma escala de intervalo sabida.
    ▶ Ver Exemplo 
    Uso de Disco: <meter value="0.6">60%</meter>

9. Elementos Interativos Dinâmicos

  • <details> e <summary>: Cria um elemento retrátil (como este próprio menu expansível!).
    ▶ Ver Exemplo 
    <details>
  <summary>Clique para expandir</summary>
  <p>Surpresa! Texto revelado com sucesso.</p>
</details>
  • <dialog>: Janela modal ou caixa de diálogo nativa do navegador.
    ▶ Ver Exemplo 
    <dialog open>
  <p>Esta é uma janela de alerta importante!</p>
</dialog>
  • <template>: Guarda pedaços ocultos de marcação HTML que serão clonados e exibidos unicamente via código JS.
    ▶ Ver Exemplo 
    <template id="molde-linha">
  <div class="linha-dinamica">Nova Info</div>
</template>
  • <slot>: Marcador de posição usado em Web Components (Shadow DOM) para injeção de conteúdos externos customizados.
    ▶ Ver Exemplo 
    <slot name="titulo-componente">Título Padrão</slot>
